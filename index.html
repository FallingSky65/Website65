Fluid Simulations

I've built a series of fluid simulations through which I learned and implmented many graphics programming and parallel computing algorithms.

Fluid65

  • This is a lagrangian (particle-based) smoothed particle hydrodynamics (SPH) fluid simulation written in C++, using raylib and raylib-cpp for graphics.
  • It runs entirely on the CPU, and on a M2 Macbook Air it can simulate real-time (60FPS) physics for 1000 particles.
  • See the code run in your own browser!
  • The source code is on GitHub and the physics kernels came from this paper by Matthias Muller.
  • This project was inspired by Sebastian Lague's YouTube video on fluid simulation.
  • I built this simulation during the summer of 2024, right before my sophomore year.
