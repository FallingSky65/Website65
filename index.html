PathTracerFS65

  • Source code: https://github.com/FallingSky65/PathTracerFS65

This is a path tracer program I wrote in 2023, before I began to use GitHub regularly. The original code is unchanged from when I last updated it on September 4, 2023.

This program renders a simple scene by simulating photon interactions with surfaces, with each intersection reflecting and accumulating colored light. The code is run entirely on a single CPU thread and the program stores the results for 1/10/50/100 photons per pixel, and displays the final result in a new window.

Here are the results, each image is 960x720 pixels, and every photon is capped at 4 bounces in the scene.

Voxel65cpp

  • Source code: https://github.com/FallingSky65/Voxel65cpp
  • Try the web demo in your browser!

This is a program I wrote in July 2024, and it implements procedural terrain generation in a voxel engine inspired by Minecraft. It is written in C++ and uses raylib (also raylib-cpp for cpp bindings) for graphics, and it implements on-the-fly optimized mesh generation.
