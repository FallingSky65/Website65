PathTracerFS65

This is a path tracer program I wrote in 2023, before I began to use GitHub regularly. The original code is unchanged from when I last updated it on September 4, 2023. You can find the source now on GitHub.

This program renders a simple scene by simulating photon interactions with surfaces, with each intersection reflecting and accumulating colored light. The code is run entirely on a single CPU thread and the program stores the results for 1/10/50/100 photons per pixel, and displays the final result in a new window.

Voxel65cpp

  • This is a program I wrote in the Summer of 2024, and it implements procedural terrain generation in a voxel engine inspired by Minecraft.
  • It is written in C++ and uses raylib (also raylib-cpp for cpp bindings) for graphics, and it implements on-the-fly optimized mesh generation.
  • See the code run in your browser!

Fluid Simulations

I've built a series of fluid simulations through which I learned and implmented many graphics programming and parallel computing algorithms.

Fluid65

  • This is a lagrangian (particle-based) smoothed particle hydrodynamics (SPH) fluid simulation written in C++, using raylib and raylib-cpp for graphics.
  • It runs entirely on the CPU, and on a M2 Macbook Air it can simulate real-time (60FPS) physics for 1000 particles.
  • See the code run in your own browser!
  • The source code is on GitHub and the physics kernels came from this paper by Matthias Muller.
  • This project was inspired by Sebastian Lague's YouTube video on fluid simulation.
  • I built this simulation during the summer of 2024, right before my sophomore year.
